# 🚀 Futuristic Calculator  
**A cyber-styled calculator with smooth animations and modern UX**

Futuristic Calculator is a visually striking, next-gen calculator built using **pure HTML, CSS, and JavaScript**.  
Designed with a **cyberpunk aesthetic**, fluid interactions, and keyboard-friendly controls, it turns a simple calculator into a polished UI experience.

---

## ✨ Features

- ⌨️ **Typing Animation Display** – Smooth, futuristic input feedback  
- 🌗 **Dark / Cyber Theme Toggle** – Switch themes seamlessly  
- 🖱️ **Keyboard Support** – Fully operable via keyboard  
- 🎨 **Futuristic UI Design** – Neon glow, cyber visuals, and clean layout  
- ⚡ **Instant Calculations** – Fast, responsive interactions  

---

## 🧠 Design Philosophy

- Minimal logic, maximum visual impact  
- UI-first approach with smooth micro-interactions  

---

## 🛠 Tech Stack

- **HTML5** – Semantic structure  
- **CSS3** – Animations, gradients  
- **Vanilla JavaScript** – Logic & interactivity  

❌ No frameworks  
❌ No libraries
